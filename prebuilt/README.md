# prebuilt/

Drop optional build inputs here:

- `mclovin.keystore`  — APK signing keystore (auto-generated by build_app.sh on
  first run if absent).
- `zipsigner.jar`     — AOSP SignApk / zip-signer to sign the flashable zip. If
  absent, the zip ships unsigned (disable zip verification in TWRP).

These are intentionally not committed; they are environment/secret inputs.
